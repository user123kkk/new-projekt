# Scarcity effect
Kind: psychological mechanism

## Definition
"A button that says buy now doesn't feel urgent. But if you say only a few left in stock, people feel more eager to buy." (38) The effect on screen: a red badge "only 5 in stock!" next to a "buy now" button.

Note: Usable only when the stock or limit is real and current; invented, reset or permanent stock text is deception (rules 1, 4). The felt effect is described as fear of missing out: see [[fear-of-missing-out]].
