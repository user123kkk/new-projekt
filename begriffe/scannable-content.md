# Scannable content
Kind: tactic

## Definition
"People don't read, they scan." Websites and ads are built so that the eye finds the point along an F or Z shaped path. (39)

Note: F and Z patterns named without a source. The 'misspelled text is still understood' claim is shown only with swapped inner letters and is not a licence for spelling errors.
